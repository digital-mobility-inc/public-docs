On-Premises

DMI runs on infrastructure hosted and controlled by the client.

Infrastructure & architecture

  • Client provides servers/VMs, storage and networking
  • DMI application and data run locally
  • Client plans capacity, backups and recovery

Security & data governance

  • Client controls network and physical access
  • Data stays in the designated environment, subject to approved transfers
  • Define encryption, audit logs and support access

Responsibilities

  • Client: infrastructure, network and recovery
  • DMI: application deployment and agreed support
  • Joint: updates, monitoring and incident response

Commercial & operational considerations

  • Client pays for on-premises infrastructure and operating costs
  • Expansion may require additional capacity
  • Agree on patching, recovery and remote access

SLA & service responsibilities

  • Availability: DMI covers the application only within the agreed support scope; client owns server, power and network uptime.
  • Response & escalation: DMI handles application incidents; client handles infrastructure incidents; both coordinate cross-system issues.
  • Recovery: client owns backups and infrastructure restoration; DMI supports application recovery as agreed.
  • Define support hours, response targets, restoration targets, maintenance windows and exclusions in the contract.

DMI-Managed Cloud

DMI hosts and operates the platform in its managed cloud environment.

Infrastructure & architecture

  • DMI provisions and operates hosting
  • DMI manages application deployment and monitoring
  • Capacity, backups and recovery follow the agreement
  • Private or dedicated hosting requires confirmation

Security & data governance

  • Hosting: AWS Canada (Central), ca-central-1
  • DMI manages hosted infrastructure security
  • Client manages its users and endpoint security
  • Define encryption, logs and incident notifications

Responsibilities

  • DMI: application deployment
  • DMI: hosting, maintenance and application support
  • Client: users, connectivity and client-side integrations
  • Joint: security reviews and incident coordination

Commercial & operational considerations

  • DMI charges the client for cloud hosting and DMI services
  • Define usage limits, support hours and SLAs
  • Agree on data export and deletion at exit

Key decision

  • Confirm service levels and data-handling terms.

SLA & service responsibilities

  • Availability: DMI owns the agreed hosted-platform uptime commitment.
  • Response & escalation: DMI monitors and responds to hosted-platform incidents; client handles local connectivity and endpoints.
  • Recovery: DMI manages backups and platform restoration within the contracted scope.
  • Define support hours, response and restoration targets, maintenance windows, exclusions and any service credits in the contract.

Client-Managed Cloud

DMI runs in the client’s own cloud account or tenancy.

Infrastructure & architecture

  • Client provides cloud account, network and resources
  • DMI deploys supported application components
  • Client approves access and deployment changes
  • Assign scaling, backup and recovery ownership

Security & data governance

  • Client selects provider, region and cloud policies
  • Client controls cloud permissions and billing
  • DMI receives approved, limited access
  • Agree on encryption, logs and data transfers

Responsibilities

  • Client: cloud account and infrastructure
  • DMI: application deployment and agreed support
  • Joint: patching, monitoring and incident response

Commercial & operational considerations

  • Client pays for cloud infrastructure and usage
  • DMI licensing and support are agreed separately
  • Define provisioning, cost and recovery approvals

Key decision

  • Assign an owner for each cloud and application operation.

SLA & service responsibilities

  • Availability: DMI covers the application; client owns cloud infrastructure, network and account availability.
  • Response & escalation: DMI handles application incidents; client handles cloud incidents; both coordinate cross-system issues.
  • Recovery: client owns cloud backups and infrastructure restoration; DMI supports application recovery as agreed.
  • Define support hours, response targets, restoration targets, maintenance windows and exclusions in the contract.
